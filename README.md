# گل‌بان 🌿 — دستیار هوشمند نگهداری گل و گیاه

یک وب‌اپلیکیشن سبک و زیبا برای مدیریت گل و گیاهان خانگی یا گلخانه‌ای، با قابلیت شناسایی خودکار گیاه از روی عکس با هوش مصنوعی OpenAI.

## محتوای پروژه
```
golban-app/
├── index.html   ← فایل اصلی، همین را باز کنید
├── style.css
├── app.js
└── README.md
```

## نحوه اجرا (ویندوز)
1. پوشه `golban-app` را در جایی از سیستم خود ذخیره کنید.
2. روی فایل **index.html** دابل‌کلیک کنید تا در مرورگر پیش‌فرض (کروم، اج و…) باز شود.
3. همین! نیازی به نصب یا اینترنت خاصی نیست، فقط برای تشخیص هوش مصنوعی به اینترنت نیاز دارید.

> اگر مرورگر شما هنگام تماس با OpenAI خطای شبکه داد (به‌ندرت پیش می‌آید)، به‌جای دابل‌کلیک، یک سرور محلی ساده اجرا کنید:
> در پوشه پروژه، ترمینال را باز کرده و دستور `python -m http.server 8000` را بزنید، سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

## راه‌اندازی هوش مصنوعی

### گزینه رایگان — Google Gemini (پیشنهادی)
1. به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) بروید و با اکانت گوگل وارد شوید.
2. روی «Create API key» بزنید — **بدون نیاز به وارد کردن کارت بانکی** یک کلید رایگان می‌گیرید.
3. داخل اپلیکیشن، از منوی سمت راست وارد «تنظیمات» شوید، ارائه‌دهنده را روی «Google Gemini» بگذارید، کلید را وارد و «ذخیره تنظیمات» را بزنید.
4. مدل `gemini-2.5-flash-lite` بیشترین سهمیه رایگان روزانه را دارد و برای شناسایی گیاه کاملاً کافی است.

> توجه: سطح رایگان Gemini محدودیت تعداد درخواست در روز دارد (برای استفاده شخصی بیش از کافی است) و ممکن است گوگل هر از چندگاهی این سهمیه را تغییر دهد.

### گزینه پولی — OpenAI
1. به [platform.openai.com/api-keys](https://platform.openai.com/api-keys) بروید و یک کلید API بسازید (نیازمند حساب کاربری و شارژ حساب OpenAI است، چون دیگر اعتبار رایگان نمی‌دهد).
2. داخل اپلیکیشن، ارائه‌دهنده را روی «OpenAI» بگذارید، کلید را وارد و ذخیره کنید.
3. مدل پیشنهادی برای شروع: `gpt-4o-mini` (سریع‌تر و ارزان‌تر). برای دقت بیشتر می‌توانید `gpt-4o` را انتخاب کنید.

کلید شما فقط در حافظه محلی همین مرورگر (`localStorage`) ذخیره می‌شود و مستقیماً از مرورگر شما به سرویس انتخابی ارسال می‌گردد؛ به هیچ سرور دیگری فرستاده نمی‌شود.

## استفاده از اپلیکیشن
- **افزودن گیاه:** روی «افزودن گیاه» بزنید، عکس گیاه را بارگذاری کنید و «شناسایی با هوش مصنوعی» را بزنید. اطلاعات نوع گیاه، نیاز نوری، دما، رطوبت، خاک، کوددهی، سمیت و آفات رایج به‌صورت خودکار پر می‌شود و می‌توانید قبل از ذخیره ویرایششان کنید.
- **بدون هوش مصنوعی هم می‌شود:** اگر نخواستید از AI استفاده کنید، گزینه «ورود دستی اطلاعات» را بزنید و فرم را خودتان پر کنید.
- **آبیاری:** روی دکمه «آبیاری شد» در هر کارت یا داخل صفحه جزئیات گیاه بزنید تا تاریخ آبیاری ثبت و برنامه بعدی محاسبه شود.
- **جست‌وجو و فیلتر:** از نوار بالای صفحه برای جست‌وجوی نام گیاه یا فیلتر بر اساس وضعیت آبیاری استفاده کنید.
- **پشتیبان‌گیری:** در بخش تنظیمات می‌توانید از کل باغچه‌تان یک فایل JSON خروجی بگیرید یا از فایل قبلی بازیابی کنید — مفید برای انتقال بین دستگاه‌ها یا مرورگرها.

## نصب روی موبایل (اندروید)
این پروژه الان یک **PWA** (اپلیکیشن وب قابل‌نصب) هم هست: فایل‌های `manifest.json`, `service-worker.js` و آیکون‌ها اضافه شده‌اند. برای اینکه واقعاً روی گوشی به‌شکل یک آیکون نصب‌شده و آفلاین کار کند، باید پروژه از طریق یک آدرس http/https باز شود (نه صرفاً دابل‌کلیک روی فایل) — مثلاً با آپلود رایگان روی GitHub Pages، Netlify یا Vercel.

اگر می‌خواهید یک **فایل APK واقعی** برای نصب مستقیم داشته باشید، ساده‌ترین و رایگان‌ترین راه، ترکیب همین PWA با ابزار PWABuilder است (مراحل را در پیام بعدی توضیح داده‌ام).

## نکات فنی
- تمام اطلاعات گیاهان در `localStorage` مرورگر ذخیره می‌شود (بدون نیاز به بک‌اند یا دیتابیس).
- عکس‌ها پیش از ارسال به هوش مصنوعی به‌صورت خودکار فشرده می‌شوند تا سریع‌تر آپلود شوند.
- کد به‌صورت HTML/CSS/JS خالص نوشته شده تا بدون نیاز به نصب Node یا هیچ ابزار دیگری، مستقیماً در مرورگر اجرا شود.

اگر خواستید ادامه‌اش دهیم (مثلاً یادآوری ایمیلی، اپ موبایل، یا همگام‌سازی ابری بین چند دستگاه)، هر زمان که خواستید بگویید تا از همین‌جا ادامه بدهیم. 🌱
